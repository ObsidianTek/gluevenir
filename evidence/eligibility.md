# Eligibility and submission requirements

Verified against the official rules on 2026-08-15. This records project-level
requirements only; personal entrant eligibility and conflict-of-interest
self-attestations remain pending.

- Submission period: 2026-06-30 10:00 EDT through 2026-08-18 17:00 EDT.
- The submission must be a newly created agentic application using
  CockroachDB as persistent memory and deployed on AWS.
- At least two listed CockroachDB tools must be meaningfully integrated.
- At least one AWS service must power the agent environment.
- The repository must be public and open source, include a visible open-source
  license, source, dependencies, examples where applicable, and setup/run
  instructions.
- A functional public demo URL and a public video under three minutes are
  required; the video must show the project and CockroachDB memory layer
  working.
- The submission must identify each CockroachDB and AWS tool actually used and
  explain what it does.
- Pre-existing work must be disclosed and third-party licenses honored.

Primary sources:

- https://cockroachdb-ai.devpost.com/rules
- https://cockroachdb-ai.devpost.com/resources
